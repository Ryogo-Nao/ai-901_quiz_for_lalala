# 利用しているデータのライセンス表記

`src/data/` の JSON は、下の2つの公開データから `npm run data:build` で作っています
(どの時点のデータかは `src/data/sources.json` に記録)。
それぞれのライセンスが求める著作権表示を、ここに残します。

ポケモン、およびポケモンのキャラクター名は、任天堂・クリーチャーズ・ゲームフリークの商標です。
このアプリは個人の学習用に作った非公式のファンツールで、これらの会社とは関係ありません。
下のライセンスは「そのプログラムやデータ集」に対するもので、ポケモンそのものの権利を与えるものではありません。
