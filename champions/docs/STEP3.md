# ステップ3の解説: チーム編成

## 1. このステップで出来たこと

- チームの作成、名前の変更、並べ替え、複製、削除(最大10チーム)
- チームのメンバー: 保存した個体から選んで追加、並べ替え、外す(1チーム最大6体)
- 上限に達したら、ボタンが押せなくなり、理由を表示する
- 個体を削除すると、その個体が入っていたチームからも外れる。削除の確認に、外れるチームの名前を出す
- 個体の一覧に、その個体が入っているチームの名前を表示
- 編集画面の上の帯を、画面の端から端まで届く色つきの帯に変更(スクロール中も下のカードと見分けがつく)

## 2. 動作確認の方法

### 2.1 自動テスト

```bash
npm test       # 「167 passed」と出れば合格
```

### 2.2 画面

先に「個体」の画面で、個体を7体以上保存しておいてください。

| # | 操作 | 期待する表示 |
|---|---|---|
| 1 | 「チーム」→「+ 新しく作る」 | 「チーム1」という名前で編集画面が開く |
| 2 | チーム名を変えて、入力欄の外をタップ | 上の帯の名前が変わる |
| 3 | 「追加」を6回押す | メンバーが6体になり「6 / 6」 |
| 4 | 7体目を追加しようとする | 「追加」が押せない。「1チームは6体までです」と表示 |
| 5 | メンバーの ↑ ↓ を押す | 並び順が変わる。1番目の ↑ と最後の ↓ は押せない |
| 6 | 「外す」を押す | メンバーが減り、下の候補に戻る |
| 7 | 「← 一覧」→「複製」 | 「(名前) のコピー」が増える。メンバーは同じ |
| 8 | チームの ↑ ↓ を押す | チームの並び順が変わる |
| 9 | チームを10個まで作る | 「10 / 10」。「+ 新しく作る」と「複製」が押せず、理由が表示される |
| 10 | ページを再読み込みする | チームも、メンバーも、並び順も残っている |
| 11 | 「個体」で、チームに入っている個体の「削除」を押す | 確認に「次のチームからも外れます: …」と出る |
| 12 | 「削除する」→「チーム」を見る | その個体がチームから外れている。ほかのメンバーは残っている |

編集画面でスクロールすると、上の帯(← 一覧 など)が色つきで残ることも確かめてください。

## 3. 仕組み

### 3.1 チームは、個体の「写し」ではなく id を持つ

```ts
export interface Team {
  id: string;
  name: string;
  memberIds: string[];   // 個体の id を最大6つ。この配列の順番が、そのまま並び順
  order: number;         // チーム一覧での並び順
}
```

- 個体を編集すると、その個体が入っているすべてのチームに反映される(写しを持たないため)
- 同じ個体を、複数のチームに入れられる
- チームの複製は、id の並びを写すだけ。個体は増えない
- チームを削除しても、個体は消えない

### 3.2 決まりは `domain/team.ts` に、保存は `storage/teams.ts` に

| ファイル | 役割 |
|---|---|
| `src/domain/team.ts` | チームの形と決まり(最大6体、同じ個体は1回だけ、並べ替え、複製)。純粋関数 |
| `src/storage/teams.ts` | チームの読み書き。最大10チームのチェック |
| `src/features/teams/TeamsPage.tsx` | 保存データを読む・書く。一覧と編集のどちらを出すか決める |
| `src/features/teams/TeamList.tsx` | 一覧を表示するだけ |
| `src/features/teams/TeamEditor.tsx` | 1チームを編集するだけ |
| `src/components/IndividualSummary.tsx` | 個体1体ぶんの要約。個体の一覧とチームの画面で共通に使う |

「7体目は足せない」という決まりは、画面ではなく `addMember` の中にあります。

```ts
export function addMember(team: Team, individualId: string): Team {
  if (isTeamFull(team) || team.memberIds.includes(individualId)) return team;   // 何も変えない
  return { ...team, memberIds: [...team.memberIds, individualId] };
}
```

画面のボタンを押せなくしているのは「押しても何も起きない」ことを利用者に伝えるためで、
決まりを守っているのはこの関数です。

### 3.3 並べ替えは「取り出して、差し込む」

```ts
const result = [...list];                    // 写しを作る(元の配列は書き換えない)
const [item] = result.splice(fromIndex, 1);  // fromIndex 番目を取り出す
result.splice(toIndex, 0, item);             // toIndex 番目に差し込む
```

メンバーの並べ替えと、チーム一覧の並べ替えは、同じ `moveItem` を使っています。

### 3.4 個体の削除と、チームから外すことを、1まとまりで行う

`storage/individuals.ts` の `deleteIndividual` は、個体を消すことと、チームから外すことを
1つのトランザクションで行います。途中で失敗しても「個体は消えたのに、チームには残っている」
という状態にはなりません。

### 3.5 チームは「保存」ボタンなしで、すぐ保存する

個体の編集は、まとめて変えてから保存します。チームは、1回の操作(追加、外す、並べ替え)が小さく、
やり直しも簡単なので、操作のたびに保存します。チーム名だけは、1文字ごとに保存しないよう、
入力欄から離れたとき(または Enter を押したとき)に保存します。
