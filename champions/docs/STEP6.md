## 2. PWA とは

PWA(プログレッシブ Web アプリ)は、Web ページを、アプリのように使えるようにする仕組みです。次の2つの部品で出来ています。

| 部品 | ファイル | 役割 |
|---|---|---|
| マニフェスト | `public/manifest.webmanifest` | アプリの名前、アイコン、色。「ホーム画面に追加」したときの見た目を決める |
| サービスワーカー | `src/sw-template.js` → ビルドで `dist/sw.js` | アプリのファイルを端末に保存しておき、通信なしでも開けるようにする |

サービスワーカーは、どのファイルを保存しておくかの一覧を必要とします。
ビルドするたびにファイル名が変わるので、`vite.config.ts` の中の小さな追加機能が、
ビルドの最後に一覧を書き込んで `dist/sw.js` を作ります。

- ページそのもの(HTML)は、まず通信で最新を取りに行き、だめなら保存してあるものを使う → 更新がすぐ届く
- プログラムや見た目のファイルは、保存してあるものを使う → 速く、通信なしでも動く
- 開発中(`npm run dev`)は、サービスワーカーを登録しない(古いファイルが使われ続けて混乱するため)

## 3. 動作確認の方法(PC)

```bash
npm run build      # 公開用のファイルを dist/ に作る
npm run preview    # それを手元で表示する → http://localhost:4173/
```

1. 開いて、個体を1体保存する
2. ブラウザの開発者ツールで「オフライン」にする(Chrome: F12 → Network → Offline)
3. ページを再読み込みする → アプリが開き、保存した個体も出る

## 4. 公開のしかた(GitHub Pages)

PWA として使うには、`https://` で始まるアドレスで公開する必要があります。
このリポジトリには、GitHub Pages に公開するための手順書(`.github/workflows/deploy-pages.yml`)を入れてあります。
**自動では動きません。** 次の手順で、ご自分で実行してください。

1. このブランチ(`claude/modest-davinci-9glve4`)の内容を `main` に取り込む(プルリクエストを作ってマージする)
2. GitHub のリポジトリのページで **Settings → Pages** を開き、**Source** を **GitHub Actions** にする
3. **Actions** タブ → **Deploy to GitHub Pages** → **Run workflow** を押す
4. 終わると、次のアドレスで公開される
   - アプリ: `https://(ユーザー名).github.io/ai-901_quiz_for_lalala/champions/`
   - 既存のクイズ: `https://(ユーザー名).github.io/ai-901_quiz_for_lalala/`(いままでどおり)

注意:

- いま、クイズを「ブランチから公開」の設定で公開している場合、手順 2 で公開の方式が変わります。
  手順書はクイズ(`index.html`)も一緒に公開するので、クイズのアドレスは変わりません
- リポジトリが公開(Public)なら、公開したページは誰でも見られます。保存データは各自の端末の中だけにあり、ほかの人には見えません
- アプリを更新したら、もう一度 手順 3 を実行します

## 5. iPhone のホーム画面に追加する

1. Safari で、公開したアプリのアドレスを開く
2. 共有ボタン(四角から矢印が出ている印)→「ホーム画面に追加」
3. ホーム画面のアイコンから開くと、アドレスバーの無い、アプリのような画面で開く

注意:

- 保存データは「そのアドレス」ごとに別です。確認用のページ(claude.ai)で保存した個体は、公開したアプリには出ません。
  移したいときは、確認用のページの「設定」で書き出し、公開したアプリで読み込んでください
- iPhone では、長いあいだ(数週間)開かないと、ブラウザが保存データを消すことがあります。
  ホーム画面に追加したアプリは、その対象になりにくいとされていますが、大事なデータは「設定」から書き出して控えを取ってください

## 6. スマホ対応で行っていること

- まずスマホ向けに書き、画面が広いときだけ配置を変える(モバイルファースト)
- 指で押す部品は、高さ 40px 以上
- 画面切り替えのタブは、スマホでは下、PC では上
- 編集画面の「← 一覧・保存」の帯と、ダメージ計算の結果は、スクロールしても画面に残る
- 端末の「暗い画面」の設定に合わせて色が変わる
- 画面上部の切り欠きや、下のホームバーに重ならないよう、余白を取る(`env(safe-area-inset-*)`)
